# 📖 What is a Network Cable?

A **network cable** is a physical medium that carries data between network devices.

It allows computers, switches, routers, printers, and servers to communicate with each other.

Without network cables, most wired networks would not exist.

```text
💻 Computer
      │
 Ethernet Cable
      │
🔀 Switch
      │
🌐 Router
      │
Internet
```

# ❓ Why Are Network Cables Important?

Network cables provide:

- 🚀 Fast data transfer
- 🔒 Secure communication
- 📡 Reliable connectivity
- ⚡ Low latency
- 📈 Stable performance

### 🌍 Real-Life Example

Your desktop computer is connected to your Wi-Fi router using an Ethernet cable.

That cable carries every website, file, and video between your PC and the router.

> 💡 **Did You Know?**
> Most enterprise networks still rely heavily on Ethernet cables because they provide faster and more stable connections than Wi-Fi.

# 🧩 Types of Network Cables

There are three main cable types used in networking.

---

# 1️⃣ Twisted Pair Cable (UTP/STP)

The **Twisted Pair** cable is the most common network cable.

Inside the cable are **four pairs of copper wires** twisted together.

The twisting helps reduce interference.

> 📌 **Diagram:** A visual illustration of this cable type will be added in a future update.
### Types

### UTP (Unshielded Twisted Pair)

- No extra shielding
- Cheapest
- Most common
- Used in homes and offices

### STP (Shielded Twisted Pair)

- Extra shielding
- Better protection from interference
- Used in factories and high-interference environments

### 🌍 Real-Life Example

Home Wi-Fi routers usually connect to computers using **UTP Ethernet cables**.

### 👍 Advantages

- Low cost
- Flexible
- Easy installation

### 👎 Disadvantages

- Limited distance (100 meters)
- Susceptible to electrical interference

---

# 📂 Cable Categories

The word **Cat** stands for **Category**.

Higher categories usually support higher speeds and better performance.

| Category | Maximum Speed | Common Use |
|-----------|---------------|------------|
| Cat5e | 1 Gbps | Home Networks |
| Cat6 | 10 Gbps (Short Distance) | Offices |
| Cat6a | 10 Gbps | Enterprise Networks |

> 💡 **Easy Trick**
>
> Higher Category = Better Performance

---

# 2️⃣ Coaxial Cable

A **Coaxial Cable** has one copper conductor surrounded by insulation and a protective shield.

It reduces signal loss over longer distances.

🖼️ *(Insert cable anatomy image here.)*

### 🌍 Real-Life Example

- Cable TV
- Cable Internet

### 👍 Advantages

- Longer distance than UTP
- Better signal protection

### 👎 Disadvantages

- Bulkier
- Less flexible
- Rarely used for modern LANs

---

# 3️⃣ Fiber Optic Cable

Fiber optic cables carry data using **light instead of electricity**.

This allows extremely fast communication over very long distances.

🖼️ *(Insert cable anatomy image here.)*

### 🌍 Real-Life Example

- Internet Service Providers (ISPs)
- Banks
- Data Centers
- Undersea Internet Cables

### 👍 Advantages

- Extremely fast
- Long-distance communication
- Immune to electromagnetic interference

### 👎 Disadvantages

- More expensive
- Fragile
- Requires specialized equipment

# 🔌 RJ45 Connector

The **RJ45 connector** is the standard connector used with Ethernet (UTP/STP) cables.

It is commonly found on computers, switches, routers, and network wall outlets.
It connects devices like:

- Computers
- Routers
- Switches
- Access Points

```text
Computer
    │
 [ RJ45 ]
    │
Ethernet Cable
    │
Switch
```

### 🌍 Real-Life Example

When you plug an Ethernet cable into your laptop, you're using an **RJ45 connector**.

# 🎨 T568A & T568B Wiring Standards

T568A and T568B define the **order of the eight colored wires** inside an Ethernet cable.

Both standards work the same—the only difference is the wire arrangement.

### T568A

```text
White/Green
Green
White/Orange
Blue
White/Blue
Orange
White/Brown
Brown
```

### T568B (Most Common)

```text
White/Orange
Orange
White/Green
Blue
White/Blue
Green
White/Brown
Brown
```

> 💡 **Remember:** Never mix T568A on one end and T568B on the other unless you're intentionally creating a crossover cable.
